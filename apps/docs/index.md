# Frontend Patterns

个人前端**方案沉淀库**：每条方案 = 「什么时候用 + 怎么用 + 代码 + 坑 + 配置项 + 给 AI 的提示词」。

不是提示词收藏夹，而是**个人工程手册**——遇到问题直接从库里调结论和代码，也能作为上下文喂给 AI，让它按你的规范生成代码。

## 已有方案

- [大数据列表/表格渲染](/patterns/big-data-table)

## 怎么用

```bash
pnpm new    # 生成一条新方案骨架
pnpm dev    # 启动本站看 demo
pnpm build  # 构建
```

新增方案的完整约定见仓库根目录的 `AGENTS.md` 文件。
