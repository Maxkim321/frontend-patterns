# 简历项目拷打预演

> 来源：秋招实际工作流（R2 面试问题「智能报价你做了什么」即来自此类复盘）。

## 什么时候用

- 投递前/面试前 1~2 天，对每条简历项目做一轮深挖预演
- 写完简历后检查哪些"写了但讲不住"的句子

## 提示词（复制即用）

```text
你是一名一线大厂的前端面试官，正在面试我。我的简历项目和目标岗位如下。

【简历项目】
（粘贴项目描述，如：参与大模型知识库问答产品（智能报价/知识库/智能问答）前端开发，
负责知识库管理端与 AI 助手界面组件，以 workspace 包形式支撑多端复用）

【目标岗位】
（粘贴 JD 关键词）

【规则】
1. 一轮只问一个问题，等我回答后再追问——不要一次列一串问题
2. 追问路线：先问"做了什么"→ 再挖"为什么这么做、有没有评估过别的方案"→
   再问"遇到最难的问题是什么、怎么定位的"→ 最后问数据/结果（要具体数字）
3. 我的回答里有含糊、夸大或讲不住的表述，直接指出并告诉我面试官会怎么戳穿它
4. 每轮结尾给一个 1~10 的"这轮回答"评分和一句改进建议
5. 全程中文，语气像真实面试官（礼貌但咄咄逼人）

开始第一轮。
```

## 使用要点

- **把 demo/代码仓库链接一起给 AI**：它能针对真实实现追问（"你的连线校验为什么前置到 isValidConnection"），比空对空简历追问有效十倍
- 被戳穿的点当场写进方案库的 README（比如"出处要说清是沉淀还是公司实现"）——**预演的产出物是修订后的口径，不是聊天记录**
- 每个项目跑 2 轮：第一轮找漏洞，修订口径后第二轮验证讲得住
- 追问链「做了什么 → 为什么 → 最难的 → 结果」就是真实面试的推进节奏，练熟这个结构比背八股有用
