# AI 技能（提示词库）

这一层沉淀的是**辅助开发的 AI 提示词/技能**——与「方案」（代码 + demo）互补：方案解决"怎么写代码"，技能解决"怎么让 AI 帮你写代码、查代码、备面试"。

收录原则：**有真实出处**（本地在用的 skill、库内方案实战验证过的提示词），不收录网上抄的通用模板——提示词的价值在使用要点和踩坑，不在话术本身。

| 技能 | 场景 | 来源 |
|---|---|---|
| [Vue3 代码审查](/skills/vue-code-review) | 提 PR 前 / review 别人代码 | 本地 review skill（ZCode 实际触发） |
| [单元测试生成](/skills/unit-test-gen) | 组件 / 组合式函数补测试 | 库内方案实战 |
| [提交信息生成](/skills/commit-message) | git commit / PR 描述 | 库内约定提炼 |
| [LLM 结构化抽取](/skills/llm-json-extraction) | 自然语言 → JSON 字段（表单预填等） | form-wizard 智能报价实战 |
| [Agent 槽位收集提示词](/skills/agent-slot-filling) | 对话式收集 / slot-filling 系统提示词 | 对话式报价实战 |
| [简历项目拷打预演](/skills/interview-grilling) | 面试前让 AI 当面试官深挖 | 秋招实际工作流 |
| [报错排查喂料模板](/skills/bug-report-prompt) | 把报错/灵异 bug 喂给 AI 一次喂对 | 库内调试实战复盘 |

用法：打开对应页面，复制提示词正文，把 `【】` 占位符换成你的上下文即可。每页的"使用要点"是比提示词本身更值钱的部分——那是踩坑换来的。
